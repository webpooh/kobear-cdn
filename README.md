# kobear-cdn

코베어 인스타툰 발행용 이미지 호스팅 (public).

Instagram Content Publishing API의 `image_url` 소스로 사용됩니다.
발행되는 카드 이미지만 보관 — 전략·작업물은 비공개 `kobear-instatoon` 레포에 있습니다.

## 구조

- `ep1/` — ep1 "개발자의 아침" 카드
- 이후 에피소드는 `ep2/`, `ep3/` ...

raw URL 형식: `https://raw.githubusercontent.com/webpooh/kobear-cdn/main/<경로>`
